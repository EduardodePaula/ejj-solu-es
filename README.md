# ejj-solu-es

Repositório da EJJ Soluções em Segurança Eletrônica.

- `EJJ_fixed.html` / `manifest.json`: site institucional (landing page).
- `sistema/`: sistema interno de gestão (clientes, orçamentos automáticos,
  ordens de serviço, financeiro com boletos e contratos de manutenção
  preventiva com cláusulas geradas automaticamente). Veja
  [`sistema/README.md`](sistema/README.md) para instruções de uso e deploy.
